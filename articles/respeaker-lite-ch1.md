XIAO ESP32S3 ＋ ReSpeaker Lite で、呼び名（ウェイクワード）の聞き分けに渡す音を取り出すまで。公式の資料には書かれておらず、実機で総当たりして確かめた。

ReSpeaker Lite（Seeed）は、XMOS の XU316 がマイク 2 本の音にエコー消しや雑音消しを掛け、I2S で XIAO ESP32S3 に渡す板である。呼び名の聞き分けに向く音を出すファームも配られているが、どの口からどんな音が出るのか、どう切り替えるのかは公式には書かれていない。レジスタ表の公開を求める Issue（[#5](https://github.com/respeaker/reSpeaker_Lite/issues/5)）にも回答が無い。

以下は実機で確かめたことだけを書く。確かめていない所はそう書く。

:::message
**結論**
- ファームは v1.1.0 の `ch0-asr_ch1-mww`（48kHz の DFU 版）。ESP32 側で 16kHz に落とす
- 聞き分けには **ch1**（取り出し口 1 ＝ エコー消しだけ）を使い、**32bit のまま 16 倍**してから 16bit に落とす
- 会話用の ch0 は取り出し口を 4 → 3 に下げて AGC を外す。電源を入れ直すと 4 に戻るので、起動のたびに書く
:::

![XMOS の処理の段と取り出し口 0〜4、ch0 と ch1 の行き先](/images/respeaker-lite-1.png)
*丸数字が取り出し口。ch1 はエコー消しの直後（1）の音で、AGC を通らないので小さい。ESP32 で 16bit に落とす前に 16 倍する。ch0 は既定の 4 から 3 へ下げて AGC を外す。*

## 1. まず音を取る（公式の例のままでは動かない）

- **クロックは XMOS が親、ESP32 は子。** 公式の例は ESP32 を親にして書かれていて、そのままでは動かなかった
- **スロットは 32bit、実データは上位 16bit。** 16bit で読むと 1 秒あたりのフレーム数が 2 倍（32kHz）になって壊れる
- **見分け方：** 読んだ値の RMS が 18,900 前後なら、それは声ではなく一様な乱数（32768÷√3）。静かに見えても、実測のフレーム数が 16kHz から外れていればスロット幅が違う
- **D1（GPIO2）に触らない。** 板の中で XMOS のリセット線（High で止まる）に繋がっている。`pinMode(D1, INPUT_PULLUP)` の 1 行で XMOS が止まり、マイクが 0 フレームになった。二分探索で 1 行まで絞った

## 2. ファームを選ぶ

| 版 | レート | 分かったこと |
|---|---|---|
| v1.0.8 / v1.0.9 | 16kHz | ch0 の最後に AGC が掛かっている。取り出し口を変えるコマンドは無い（読むと status=3 で拒否） |
| v1.1.0 `ch0-asr_ch1-mww` | 16kHz は factory 版のみ／48kHz は DFU 版 | ch0 は音声認識向け、ch1 は呼び名の聞き分け向けの音を出す。**呼び名を判定する機能は無い。** 判定は ESP32 でやる |

16kHz の v1.1.0 は factory 版しか配られていない。書き込みの先（dfu-util の `alt=0`）は公式手順に無く、壊したときに戻せる保証が無いので使わなかった。公式手順どおりに `alt=1` へ 48kHz の DFU 版を書いた。

```
dfu-util -R -e -a 1 -D respeaker_lite_i2s_dfu_firmware_48k_v1.1.0_ch0-asr_ch1-mww.bin
```

48kHz と 16kHz は 3 対 1 なので、ESP32 では読むときに 3 つを平均して 1 つにし、鳴らすときは 1 つを 3 つに伸ばすだけで済む。

:::message alert
**48kHz にすると DMA の受け皿が 3 分の 1 の時間で溢れる。** 4 個 × 256 フレームは 16kHz なら 64ms、48kHz では 21ms しかない。画面の全面転送（約 29ms）の間に溢れ、つなぎ目の段差が「静かなのに RMS が数千」として出た。受け皿の数を 3 倍にして直った。
:::

## 3. 取り出し口を読み書きする（ここが総当たり）

XMOS の中の処理は、エコー消し → 2 本のマイクの合成 → 雑音消し → AGC と並んでいて、ch0・ch1 それぞれ、どの段の後の音を出すかを選べる。この話の出どころは個人の投稿（[Issue #9](https://github.com/respeaker/reSpeaker_Lite/issues/9)）だけで、書かれていたとおりの読み方では通らなかった。

| 項目 | 値 |
|---|---|
| I2C のアドレス | `0x42` |
| 設定サービス（RESID） | `0xF1` |
| ch0 の取り出し口 | 書き `0x30`／読み `0xB0`（`0x30 \| 0x80`） |
| ch1 の取り出し口 | 書き `0x40`／読み `0xC0`（`0x40 \| 0x80`） |

| 値 | 出てくる音 |
|---|---|
| 0 | マイクそのまま |
| 1 | エコー消し ← **ch1 の既定** |
| 2 | エコー消し＋2 本のマイクの合成 |
| 3 | ＋雑音消し（AGC なし） |
| 4 | ＋AGC ← **ch0 の既定** |

### 読み出しには 0x80 を立てる

公式の Arduino の例が読んでいる VNR（`0x80`）とミュート状態（`0x81`）は、もともと 0x80 が立っている番号なので、例を見ても「読むときは 0x80 を立てる」決まりに気づけない。設定サービスのコマンド番号を端から読む命令を機体に足して回したところ、応答したのは 5 つで、`0xB0` が 4、`0xC0` が 1 を返した。ch0 が AGC まで、ch1 がエコー消しだけという並びと合う。

そのほかの決まり：要求するバイト数は「欲しい数＋1」。書式を間違えると status=2 で弾かれる。

### 電源を入れ直すと戻る

ch0 を 3 に書いても、電源を入れ直すと 4 に戻っていた。起動のたびに書く。

### ch0 の AGC を外すと、エコーの残りが消えた

機体が自分の声（話し声の再生）を鳴らしている間、エコー消しの残りを AGC が持ち上げていた。音量つまみを変えても残りの大きさが変わらなかったのは、AGC が一定の大きさまで持ち上げていたためである。

| | 取り出し口 4（AGC あり） | 取り出し口 3（AGC なし） |
|---|---|---|
| 再生中に拾う残り（RMS） | 中央 1,379・最大 9,288 | **中央 2・最大 10** |
| 鳴らしていないとき | 中央 49・最大 1,169 | 中央 1・最大 12 |

AGC を外すと増幅も無くなり、普通の声が RMS 36〜113 までしか入らなくなる。ESP32 で一定の倍率（16 倍）を掛けて取り戻した。倍率が一定なら、残りと声の比は変わらないので、エコー消しの効き目はそのまま残る。

## 4. 聞き分けに渡す音を決める

ch0（取り出し口 3）と ch1（取り出し口 1）、それぞれ 4 倍と 16 倍の 4 通りを、同じ時に録った音で比べた。同じモデルで、呼びかけ 5 回への当たりと、呼んでいない所で機体が起きた回数（25 秒）を数えた。

ただし、この比較に使った録音は、後にモデルの良し悪しを測ると実機と合わないと分かった物である（[物差しは現物で録る](https://zenn.dev/n416s/articles/wakeword-ja-measure)）。ch1 × 16 は当時この表で決め、今も使っているが、生の声で 4 通りを比べ直してはいない。

| 入れ方 | 当たり | 誤爆 |
|---|---|---|
| ch0 × 4 | 4/5（しきい値 0.7） | 0 |
| ch0 × 16 | 4/5（0.9） | 2 |
| ch1 × 4 | 5/5（0.7） | 0 |
| **ch1 × 16** | **5/5（0.9）・最低 0.973** | 0 |

### 倍率は 32bit の段で掛ける

ch1 は AGC が無いので、話しても RMS 40 前後にしかならない。16bit に落としてから 16 倍すると、下の 4bit ぶんの細かさが消える。32bit のスロットで受けた値にそのまま倍率を掛け、それから上位 16bit を取る。

### 倍率を上げても取りこぼしは直らなかった

呼んでも起きない回を、倍率で直せるかを測った。スピーカーで流した呼びかけ 6 回に、16・32・64・128・256 倍を当てても、結果は変わらなかった（振り切れも 0）。ただし測ったのはスピーカーで流した音に対してだけで、生の声での比較はしていない。声と周りの音が同じだけ大きくなるので、差は変わらないと見ている。

### 機体が喋った直後は、周りの音が上がる

機体に喋らせた 0.3 秒後に同じ声を流すと、声の大きさは 425〜452 で変わらず、周りの音だけが 45〜60 から 111〜147 に上がった。声と周りの差は 19dB から 10dB に縮む。
